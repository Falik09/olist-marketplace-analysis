# Приватные данные

Три CSV с разделителем-запятой необходимо разместить в `data/private/`. Названия уже подходят для проекта, поэтому они сохранены. Содержимое файлов не изменялось.

- `olist_customers_dataset.csv` — 99441 строк; 5 столбцов.
- `olist_orders_dataset.csv` — 99441 строк; 8 столбцов.
- `olist_order_items_dataset.csv` — 112650 строк; 7 столбцов.

`customer_id` соединяет заказы с клиентами; `customer_unique_id` используется для повторных покупок одного человека. `order_id` соединяет заказы с позициями; стоимость позиций сначала агрегируется до заказа. Исходные поля и их использование описаны в ноутбуке.

Данные исключены из Git. До проверки разрешений курса и условий распространения конкретной выгрузки храните репозиторий приватным. Приватный архив и выполненный ноутбук на GitHub не загружайте. `.gitignore` не защищает браузерную загрузку или старые коммиты.
