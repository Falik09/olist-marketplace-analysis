# Проверка воспроизводимости

Дата: 15 ноября 2026 года. Проверено на Python 3.9.6 с версиями библиотек из `requirements.txt`. Проверка совместимости установленных зависимостей (`pip check`) пройдена.

## Выполнение

Чистое ядро Jupyter выполнило **7 из 7 кодовых ячеек** по порядку с тремя предоставленными CSV. Время — около 8 секунд. Ошибок выполнения и нарушений встроенных проверок нет. Три графических вывода созданы и просмотрены: тепловая карта удержания, кривые зрелых когорт и четыре месячные метрики.

Исправлен перенос выражения в одной f-строке, несовместимый с Python 3.9. Выражение `repeat_share:.2%` и все расчёты сохранены. Остальные изменения: имя ноутбука, путь `data/private/`, инструкция запуска и очистка выводов в версии для GitHub.

Числа воспроизведены новым запуском и совпадают с основными авторскими выводами. Контрольные суммы неизменённых CSV находятся в приватном архиве. Выполненный ноутбук сохранён в приватном архиве, а версия для GitHub не содержит выводов.

## Ограничения

Это исторический анализ и план эксперимента. Экспериментальных групп, p-value и доказанного эффекта внедрения здесь нет. Сценарная оценка 974 дополнительных заказов — верхняя граница при устранении всех выбранных отмен, а не прогноз. Низкий retention не доказывает отсутствие PMF; GMV не является выручкой или прибылью платформы.

На скриншоте задания указано удержание по оформлению заказа; автор выбрал более узкое событие — оформление впоследствии доставленного заказа. Определение явно описано в ноутбуке, но соответствие требуемой трактовке задания следует согласовать отдельно. Проверка выполнения не означает подтверждения всех причинных допущений или разрешения на публикацию курса.
