# Загрузка проекта на GitHub

1. Распакуйте архив `olist-marketplace-analysis-github.zip`. Архив с пометкой `PRIVATE` храните отдельно и не загружайте на GitHub.
2. Создайте репозиторий `olist-marketplace-analysis` с видимостью **Private**. Если он уже существует, сначала проверьте, что он приватный.
3. Через **Add file → Upload files** добавьте содержимое папки проекта из первого архива. Добавляйте файлы, а не сам ZIP. Включите скрытый файл `.gitignore`; при необходимости включите показ скрытых файлов.
4. Проверьте список перед сохранением: там не должно быть CSV, приватного архива, папки `data/private/` или выполненного ноутбука. Браузерная загрузка не учитывает `.gitignore`.
5. Сохраните изменения и ещё раз проверьте приватность репозитория.

## Вариант через Git

Для нового пустого приватного репозитория из папки проекта:

```bash
git init
git add README.md VALIDATION.md GITHUB_UPLOAD.md requirements.txt .gitignore olist_marketplace_analysis.ipynb data/README.md
git diff --cached --stat
git status --short
git commit -m "Подготовить анализ Olist для портфолио"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/olist-marketplace-analysis.git
git push -u origin main
```

Замените `YOUR_USERNAME` своим именем на GitHub. Если в репозитории уже есть изменения, сначала клонируйте его и скопируйте туда файлы проекта. Не используйте принудительную перезапись истории.

После локального выполнения очистите выводы всех ячеек перед добавлением ноутбука в Git. Правило исключения не защищает уже отслеживаемые файлы.

Перед публичной публикацией получите разрешение курса, проверьте код и текст на ограничения и идентификаторы, а также проверьте всю историю репозитория. Отсутствия CSV в текущей версии недостаточно, если они были в прошлых коммитах. В рамках подготовки архива загрузка на GitHub и изменение видимости не выполнялись.
